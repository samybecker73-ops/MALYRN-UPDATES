# MALYRN v0.9.2 — Migration vers KAVIO UPDATE SERVICE

## Nouveautés
- Migration du client MALYRN vers le service central de mises à jour KAVIO.
- Version applicative portée à 0.9.2.
- Cache du Service Worker versionné en 0.9.2 afin que les installations 0.9.1 récupèrent la nouvelle application et le nouveau canal.
- Notes de version désormais servies par KAVIO.

## Fonctionnement
Le client lit le manifeste à l’adresse :
`https://kavio-update-service.samy-becker73.workers.dev/malyrn/latest.json`

Le dépôt public historique `MALYRN-UPDATES` annonce cette version de transition aux anciennes installations 0.9.1. Après mise à jour, le client interroge directement KAVIO.

Le service KAVIO publie les métadonnées, mais ne déploie pas les fichiers de la PWA. Les fichiers applicatifs doivent être déployés sur l’origine HTTPS de MALYRN pour que le navigateur puisse installer le nouveau Service Worker.
